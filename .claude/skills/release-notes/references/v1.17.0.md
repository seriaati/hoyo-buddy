## Sponsor Command and Free User Changes
Added `/sponsor` to show current sponsor perks and your sponsor status.

Changes to free users:
- Link up to 6 game accounts.
- Have up to 5 custom images per character. Existing custom images exceeding the limit are kept, but if you want to add more custom images, you have to remove existing ones.
- 5 AI image generation per day (resets at 00:00 UTC+8)
